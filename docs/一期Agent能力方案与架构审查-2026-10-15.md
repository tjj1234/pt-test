# 北极星一期 Agent 能力方案与架构审查

日期：2026-10-15。审查基线：远端 main `62f5b46dc83a05f39b6f910ef778496b5b1495ca`。性质：开发方案评审稿；不是新的项目进度总文档，不代表以下事项已经开发或通过验收。

## 结论与一期边界

架构前提（用户补充）：所有用户共用同一套 DSH 基座，通过各自 workspace 隔离。DSH 代码、版本与基础能力统一维护，用户数据、凭据与会话上下文按可信身份和 workspace／conversation 归属隔离。共用基座不等于共用一个对话 session，也不能据此推断必须共用单个 OS 进程；进程拓扑属于运行层实现，不为每位用户单独安装、分叉或维护一套 DSH。

一期交付目标：用户拥有独立账号和工作区，在多个对话中并行完成文本、视觉理解、文档分析、图片／视频生成任务；默认 AUTO，根据任务与附件选用经过验证的 PT 模型；任务可追踪、停止、重连，产物可预览和下载，用量与故障可核验。保留现有归因／GA 等工具，不扩大广告业务范围。

二期：定时业务流、周期触发、批处理、跨成员协作、邀请加入租户、通知和业务系统回写。注意，一期长任务队列属于 Agent 执行基础设施，不能随“业务调度二期”一并推迟。

“完整 Agent”按以下可验收场景界定，不等同于支持世界上所有模型、文件格式和外部工具。所有模型调用继续经 PT；若 PT 缺少某项能力，需要明确缺口并确认供应方案，不能静默调用另一个供应商。

## 1. 多对话并行与模型切换

同一对话连续追问已经支持。本方案将新增项理解为“同一用户多个对话同时执行”：A 对话生成视频时，B 对话仍可分析文件；同一对话内默认顺序执行，避免两轮同时改写历史。

当前两层限制：server.cjs 的 runningJobs 按用户占位；persistent-runner.mjs 的 Promise 队列按租户串行。仅把用户锁改成对话锁无法实现真实并发。另外 currentTenantId、lastReport、lastMediaRouteResult、lastMediaRouteModel 等为 runner 级变量，直接并发存在结果混用风险。

并发方案必须复用同一套 DSH 基座，不为用户各部署一套。此前建议的“有上限的会话 worker 池”属于运行层候选：服务端统一分配 runId；执行槽位可启动同一份 DSH 程序的独立进程，运行态目录单独管理；空闲会话可复用，资源紧张时回收并从持久上下文恢复。初始每用户允许 2 个并行执行，限额可配置，并设置全局上限；实际槽位数以机器内存、CPU、PT 限流和压测结果定。每对话同一时刻 1 个运行中任务，其他请求显式排队。任务输出目录独立，修改共享文件时串行保护。该候选不是已拍板的单用户独立基座部署方案。

另一方案是在现有 DSH 运行进程内并发多个 agent／session，资源效率更好，但需先验证 SDK 并发与取消隔离，再把全部执行上下文改为 session／run 局部状态；不作为未经验证即可承诺的轻量修复。最终拓扑须结合实际运行方式确定；共享基座与 workspace 隔离这个产品前提保持不变，开发量暂保留为区间估算。

模型切换示例：对话 A 首问用模型 X，创建了热 agent；用户在下拉框选 Y 后继续 A，当前代码仍复用 X 的 agent；新建 B 才使用 Y。切换不修改历史答案。当前日志若记录用户选择的 Y，也可能与实际执行 X 不符。

目标语义：模型选择属于对话配置；用户默认选择 AUTO，也可指定当前对话模型。切换在下一轮生效，进行中的轮次维持原模型。优先使用经验证的 SDK 安全切换能力；不支持时，在轮次边界关闭旧 session，用持久消息、工具证据和附件引用重建。长历史按上下文预算处理，明确展示摘要／截断边界，不重复执行历史工具。每轮展示实际选中的执行模型。AUTO 控制器与生成模型可同时不同。

## 2. AUTO：模型目录、任务规划与执行路由

现有媒体路由是四种 taskType 到 Seedream／Wan 的固定映射；它不同于跨模型能力池选优的 AUTO。对话模型下拉框也不是生成模型选择器。

推荐链路：用户输入与附件 → 任务理解 → 能力需求 → 可用模型过滤 → 路由策略 → 协议适配器 → PT → 任务／产物／用量记录。复杂任务可包含多个步骤，例如“读产品图，生成海报，再生成视频”，不能整轮只选一个模型后强行完成所有工作。

模型目录需要 modelId、供应方、模型版本、输入／输出模态、任务类型、协议与端点、工具调用／流式／结构化输出支持、上下文与文件限制、生成参数限制、价格及单位、可用性、验证状态和最后校验时间。PT 未返回的字段标未知，由官方端点说明与配置补充；不得凭模型名猜测。标签、多模态、协议支持分别维护，支持 Chat Completions 不等于支持 vision 或 tool calling。

目录同步：启动读上次有效缓存；每日同步元数据并支持管理员手动刷新；同步失败保留旧目录并展示时间；新模型先进入待验证状态，经过轻量协议测试与代表任务验收后进入 AUTO。每日同步不等于每日付费试跑所有模型。公共能力目录与用户 Key 可访问范围分开，避免用某员工 Key 的结果替所有人授权。

路由规则：

| 场景 | 处理 |
|---|---|
| 普通问答、简单总结 | 能力满足的低延迟／低成本对话模型 |
| 分析图片、图表或截图 | 支持图像理解的模型，不调用生图模型冒充理解 |
| 制作／修改图片 | 图像生成／编辑模型，并检查参考图能力 |
| 制作视频 | 支持目标时长、比例、参考素材的异步生成模型 |
| 语音／录音 | 原生音频理解或经验证的转录链路 |
| 视频理解 | 原生视频理解；或带时间戳的抽帧＋音轨处理，并说明采样范围 |
| 长文档／多文档比较 | 检索相关片段后分析，必要时选择长上下文模型 |
| 需要查数据或联网 | 控制模型具备工具调用能力；结果来自真实工具 |

先按能力、用户权限、文件限制和预算做硬过滤，再按质量、延迟、价格和稳定性排序；“均衡”作为默认策略，“更快／更高质量”作为可选偏好。显式要求“生成视频”不能回退成一段视频文案后宣称成功。低置信度只问关键歧义，不让每次简单输入都多走一次昂贵分类。

错误处理区分参数不兼容、无权限、限流、余额不足、供应商不可用和任务状态未知。已返回供应商 taskId 的付费生成请求先查询原任务，不能因本地超时直接重复提交。没有供应商幂等支持时，不承诺端到端恰好一次。替换模型不能绕过预算和能力约束。

每轮记录 requestedMode、resolvedModel、routeReason、catalogVersion、attemptId、供应商请求／任务 ID；网关内部再次路由但未返回真实上游模型时明确未知，不用 resolvedModel 冒充内部实际模型。

## 3. 多媒体输入

建立统一 Attachment 入口与资产 ID，上传时保存 tenantId、来源、MIME、大小、校验和、所属对话、处理状态和有效期，模型只接收经授权的引用。公共外链不可访问的私有上传使用受控转存、签名地址或供应商文件 API；不得简单把整套用户文件目录公开。

| 输入 | 一期交付 | 验收重点 |
|---|---|---|
| 图片 | 多图理解、OCR、图表解释、参考图编辑／生成 | 真正理解内容；引用具体图片；小字无法识别时说明 |
| 音频 | 转录、时间戳、总结与问答 | 可回到音频位置；噪声、多人重叠的限制可见 |
| 视频 | 画面＋声音联合理解、时间定位与问答 | 覆盖声明、关键片段引用、处理进度；不能把稀疏抽帧称为逐帧看完 |
| 混合素材 | 同轮上传图片、文档、音视频并关联使用 | 文件／片段不串号、跨用户不可读 |

视频理解与视频生成分属两种能力。TTS 也不等于 ASR。本轮公开目录不足以确认完整 ASR 可调用端点；先完成 PT 能力验证，缺失时如实登记供应依赖。建议一期约定普通文件／媒体的大小、时长、页数上限并公开展示；超限可分段处理或明确拒绝。精细说话人识别、专业剪辑不计入基础估算。

## 4. 文档问答、数据分析与产物

一期输入格式：TXT、MD、CSV、PDF（含扫描件 OCR）、DOCX、XLSX。保留结构化内容：PDF 页码，Word 标题与段落，表格 sheet／行列范围；解析任务异步执行并显示可读状态。小文件直接分析，大文件分块与租户内检索，首期可用 PostgreSQL 检索；需要语义检索时增加受控索引，不必先引入独立向量数据库。

问答答案必须带可点击来源定位；跨文档比较可标注每个事实来源；数字统计使用确定性计算并处理缺失值、日期、单位与重复数据，不能让 LLM 心算大表。支持连续追问和选择已上传资料。附件正文属于资料而非系统指令；文档里的“忽略权限”等内容不能获得工具权限。

一期私有资料检索范围以当前对话和用户明确选择的个人资料为准，不自动把全部历史文件发送给模型。长期记忆可查看、编辑、删除，区分用户确认事实与模型推断；上下文压缩保留原消息和来源引用。

统一 Artifact 保存输出：MD／HTML／PDF／CSV／XLSX、图片、视频；支持列表、预览、下载、多产物与可追溯版本，原始外部结果链接失效后仍有明确留存策略。HTML 预览禁用脚本并使用隔离 iframe；下载与预览遵守租户权限。每个产物关联 runId、来源附件、生成模型及任务，不再只留 lastReport／lastMediaRouteResult。

## 5. 任务、工具与执行安全

持久任务状态：queued → running → waiting_external → completed／failed／cancelled／interrupted；取消后供应商仍运行时另记录 externalStatus，不能伪装成已停止计费。awaiting_confirmation 仅用于真实需要用户决定的参数、费用或外部动作。

每次提交分配 runId 与幂等键，消息、工具调用、路由尝试、媒体任务、产物、日志统一关联；事件有递增序号，刷新／断线后可重连与去重。进程重启时，可查询的上游任务恢复查询；没有恢复依据的对话任务标 interrupted，不自动重复付费生成。

工具定义统一一个 registry，DSH 工具由其生成或通过可信 RPC 执行；Schema、权限、凭据、预算、风险和日志不能只在某个 HTTP 入口生效。返回模型的工具内容应含足够的真实摘要、指标、问题与来源，完整报告继续给前端；限制长度时公开范围。先修质量报告仅返回标题与评分的问题。

运行隔离采用环境变量白名单、最小文件与网络权限，worker 不继承服务器全部机密；任务输出目录独立。任意代码／不可信文件解析应在受限 worker 中执行并限制 CPU、内存、时长与网络。cwd 本身不是安全沙箱。先完成真实越界验证，再决定容器或其他隔离落地方式；不以目录命名证明强隔离。

## 6. 日志与用量：在最新实现上补全

现有新实现可复用，不重建日志页面。需要完善：

1. 用 runId／conversationId／callId／attemptId 串联主模型、每次模型请求、工具、外部任务与产物；工具真正开始时记账，完成时更新，不能仅整轮结束后回填。
2. 步骤状态与整轮状态分开。当前 persistSteps 在整轮失败／中断时将已完成步骤一并覆盖为 failed／interrupted，需保留各步骤真实结果。
3. summarize 当前对多个 assistant/message 的 usage 仅保留最后一份；需确认 DSH 协议是单请求值还是累计值，按实际语义去重汇总每次请求。两份独立 usage 的构造探针返回最后一份，证明现实现未主动累加，但不据此声称实际线上少算的确切数量。
4. 使用实际执行模型，不使用用户当前所选模型冒充旧热会话实际模型；AUTO 路由尝试和重试都可追踪。
5. usageSummary 不能只靠 COUNT(*) 判断有无 token：有 usage 行但字段全 NULL 时，COALESCE(SUM(...),0) 仍会形成假 0。本轮真实 PGlite 探针已复现 count=1、totalTokens=0。增加已知量覆盖信息，区分未知、部分已知和真实零。
6. 分开对话 Token、图片张数、视频秒数、音频时长、OCR 页数。计费按模型／供应商实际单位记录，保留原始单位与价格版本；估算费用与网关实际扣费分列，不用 Token 推算所有媒体费用。
7. 增加请求耗时／首字延迟／排队时长／成功率／错误码／过滤与导出／分页／脱敏／留存策略。心跳也记录为独立来源，用户任务统计与系统保活费用可区分。
8. 开发态示例数据仅显式开启；生产接口缺失不能回退为看似真实的示例用量。费用或账单接口不可用时显示“未接入实际账单”，不填 0。

## 9. 开发量与依赖

估算单位为有效工程人日，按熟悉现有 Node／DSH 项目的工程师在 AI 辅助下实施，包含设计、实现和模块自测；跨模块独立验收单列。不是模型生成代码耗时。基于现有能力增量开发，不重复计算已完成日志 A1–A5。不含新增全部 PT 模型／复杂视频编辑／直播语音／组织级知识库／多人协作／定时业务流；PT 可用 Key、价格数据与真实部署环境按时提供。

## 10. 二期业务流与调度

复用一期 run／attempt／event／artifact／usage 模型，新增 workflow 定义与版本、手动／定时／事件触发、时区与 DST、凭据绑定、执行互斥、幂等、有限重试、错过触发补跑策略、暂停／恢复、通知和运行历史。先做“每日数据查询→报告→通知”等固定模板，暂不先做任意拖拽 DAG。

二期模板调度版约 10–16 人日；可视化编排再加 12–20 人日；多人邀请与共享权限另计。上述估算依赖一期任务层完成。现有“调度与执行”页面在二期前应按真实功能标为上传记录，不能用页面名称宣称已经有调度。

## 11. 一期验收场景

| 场景 | 必须观察到的行为 |
|---|---|
| A 生视频、B 分析 PDF | 两任务真实并行，事件／附件／产物不串，对 A 停止不影响 B |
| 热会话从 X 换 Y | 下一轮真实请求走 Y，历史保留，日志与实际模型一致 |
| AUTO 看图／生图／生视频 | 区分理解和生成，模型具备要求的输入／输出，失败不伪装成功 |
| 录音／视频问答 | 可定位时间戳，未知／未覆盖片段说明清楚 |
| PDF＋表格跨文件问答 | 页码／sheet／行列可查，统计来自确定性计算 |
| 一轮多报告／多张图 | 全部产物保存，刷新仍在；模型能解释报告具体指标 |
| 刷新／断网／重启 | 任务状态可恢复，结果去重；上游状态未知时不重复计费提交 |
| 工具成功后整轮失败 | 已成功步骤仍成功，整轮失败另记，费用与已知量保留 |
| 多次 LLM 请求／重试 | 按协议正确累计去重；缺失数据非 0；图片／视频按自身单位记录 |
| 跨用户与不可信文件 | 用户 A 无法读 B 文件、记忆、任务、日志；附件指令不能越权 |
| 干净安装与升级 | shell 唯一实现可启动；旧数据库升级保留对话与记忆；PG 配置错误明确失败 |
