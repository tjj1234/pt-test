# 北极星 shell 迁移前置流程回滚复现

正式 shell 仍在 `tx.exec(sql)` 报 PostgreSQL `invalid message format`；shell 当前已停止。此前成功的探测没有执行 `db.migrate()` 中位于事务前的完整顺序（`CREATE TABLE IF NOT EXISTS schema_migrations`、参数化查询迁移标记，再进入事务）。下面由 systemd 临时 unit 使用正式环境和 r4 的 `db.cjs`/`db-pg.cjs`，复现这个完整前置顺序，并在事务中显式回滚；不会提交迁移或启动 HTTP 服务。

在服务器 SSH 终端执行第 8 行：

```bash
sudo systemd-run --wait --pipe --collect --unit=northstar-pg-full-preflight-20261021 -p User=northstar -p Group=northstar -p WorkingDirectory=/opt/northstar/releases/controlled-trial-20261021-r4/shell -p EnvironmentFile=/etc/northstar/northstar.env -p NoNewPrivileges=yes -p PrivateTmp=yes -p ProtectSystem=strict -p ProtectHome=yes /usr/local/bin/node -e 'const dbm=require("./db.cjs"),fs=require("node:fs");(async()=>{let x;try{x=await dbm.open({dataDir:"/var/lib/northstar/db"});await x.db.exec("CREATE TABLE IF NOT EXISTS schema_migrations (id SERIAL PRIMARY KEY,name TEXT NOT NULL UNIQUE,applied_at TIMESTAMPTZ NOT NULL DEFAULT now())");const done=await x.db.query("SELECT 1 FROM schema_migrations WHERE name = $1",["001_auth.sql"]);console.log("PREFLIGHT_OK pending="+(done.rows.length===0));await x.db.transaction(async t=>{await t.exec(fs.readFileSync("db-migrations/001_auth.sql","utf8"));await t.query("INSERT INTO schema_migrations (name) VALUES ($1)",["001_auth.sql"]);throw Error("ROLLBACK_PROBE");});}catch(e){console.log(e.message==="ROLLBACK_PROBE"?"FULL_PREFLIGHT_PROBE_OK":"FULL_PREFLIGHT_PROBE_FAILED code="+(e.code||"none")+" file="+(e.file||"none")+" line="+(e.line||"none")+" routine="+(e.routine||"none")+" message="+(e.message||""));}finally{if(x)await x.close();}})();'
```

预期若完成则输出 `PREFLIGHT_OK pending=true` 与 `FULL_PREFLIGHT_PROBE_OK`；若失败则会打印 PostgreSQL 错误码、源文件、行号和例程。回传完整输出；如错误文本出现 DSN、密码或密钥，先遮住。不要启动正式 shell 服务。
