```bash
sudo systemctl is-active northstar-shell
```

## 5. 安装 r4 shell unit 并启动

依赖安装通过后，逐条执行第 56–65 行。第 56 行备份旧 unit；第 57 行把上传的 r4 unit 装入 systemd。第 58 行摘要须等于第 68 行预期值，不匹配则停止。第 60 行验证若出现 `northstar-shell.service` 错误，停下，不执行第 61–65 行。

```bash
sudo cp -a /etc/systemd/system/northstar-shell.service /etc/systemd/system/northstar-shell.service.r3-20261021
sudo install -o root -g root -m 0644 /tmp/northstar-shell-r4.service /etc/systemd/system/northstar-shell.service
sha256sum /tmp/northstar-shell-r4.service
sudo stat -c '%U:%G %a %n' /etc/systemd/system/northstar-shell.service
sudo systemd-analyze verify /etc/systemd/system/northstar-shell.service
sudo systemctl daemon-reload
sudo systemctl enable --now northstar-shell
sudo systemctl status northstar-shell --no-pager
sudo journalctl -u northstar-shell -n 100 --no-pager
curl -fsS http://127.0.0.1:8098/healthz
```

unit SHA-256：`e91e7d86ada8ac8d6b3753ee70e4c407d4e1622f877d4c70f991f024d3562f6d`。通过条件：`northstar-shell` 为 `active (running)`，`/healthz` 返回 JSON 中 `"ok":true`。若启动失败，回传 `Cannot find module` 完整行和 require stack；遮住密码、密钥和 DSN。即使本机 health 通过，公网 HTTPS、Google OAuth、PG 用户持久化和单次 T03 调用仍须分别验收；目前不发起生成请求。
