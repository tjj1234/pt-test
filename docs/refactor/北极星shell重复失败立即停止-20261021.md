# 北极星 shell 重复失败立即停止

r4 正式 `server.cjs` 仍在启动迁移时报 `invalid message format`，systemd 的 `Restart=on-failure` 已连续重启。此前 psql、直接 `db-pg.cjs` 事务探测和临时 systemd 环境探测都成功，因此这些最小探测没有覆盖/复现完整服务器启动路径；不能据此继续启动。先停止自动重启并确认迁移状态，再基于完整启动路径定位。不要重启或手工执行迁移。

在服务器 SSH 终端逐条执行第 8–12 行：

```bash
sudo systemctl stop northstar-shell
sudo systemctl is-active northstar-shell
sudo systemctl show northstar-shell -p ActiveState -p SubState -p Result -p NRestarts
sudo -u postgres psql -d northstar -c 'SELECT name, applied_at FROM schema_migrations ORDER BY name;'
sudo journalctl -u northstar-shell -n 100 --no-pager -o short-iso
```

第 9 行应为 `inactive`。请贴出第 9–12 行结果；如果日志中包含任何 DSN、密码或密钥，请先遮住。停住后不要执行健康检查或启动命令。
