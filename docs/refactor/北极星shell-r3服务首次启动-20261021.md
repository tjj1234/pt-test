# 北极星受控试运行：shell r3 服务首次启动

analytics 本机首页已返回 HTTP 200。shell unit 绑定 r3，运行账号为 `northstar`，依赖 `postgresql.service` 和 `northstar-analytics.service`，只允许写入 `/var/lib/northstar` 下的数据目录，监听由环境文件限定在 loopback。unit 文件不含密钥。

## 1. 确认 analytics 仍运行

在服务器 SSH 终端逐条执行第 10–12 行。第 10 行必须是 `active`；若不是，停下并先回传状态/日志，不安装 shell unit。

```bash
sudo systemctl is-active northstar-analytics
sudo systemctl status northstar-analytics --no-pager
sudo journalctl -u northstar-analytics -n 80 --no-pager
```

## 2. 从 Mac 上传 shell unit

在 Mac 本机终端（不是 SSH 会话）执行第 20 行：

```bash
scp -P 22 /Users/mmdn/Downloads/pt项目/release-artifacts/northstar-shell-r3.service tongjiawan@47.237.22.191:/tmp/northstar-shell-r3.service
```

## 3. 在服务器核验并安装 unit

在服务器逐条执行第 28–30 行。第 28 行摘要应匹配第 33 行；不匹配则停下。第 29 行安装 unit；第 30 行核对权限。

```bash
sha256sum /tmp/northstar-shell-r3.service
sudo install -o root -g root -m 0644 /tmp/northstar-shell-r3.service /etc/systemd/system/northstar-shell.service
sudo stat -c '%U:%G %a %n' /etc/systemd/system/northstar-shell.service
```

预期 SHA-256：`af59b69e5e143ba18e744642424cc6216c64a6d6ebd180c228adc2fe79a30593`；unit 文件应为 `root:root 644`。

## 4. 验证 unit 后启动

逐条执行第 40–46 行。第 40 行若出现 `northstar-shell.service` 错误，停下，不执行第 41–46 行。Ubuntu 系统自带 `xfs_scrub_all` / `cloudmonitor` 警告不属于本 unit，不要修改它们。

```bash
sudo systemd-analyze verify /etc/systemd/system/northstar-shell.service
sudo systemctl daemon-reload
sudo systemctl enable --now northstar-shell
sudo systemctl status northstar-shell --no-pager
sudo journalctl -u northstar-shell -n 100 --no-pager
curl -fsS http://127.0.0.1:8098/healthz
curl -fsSI http://127.0.0.1:8098/
```

通过条件：unit 为 `active (running)`，`/healthz` 返回 JSON 中 `"ok":true`，首页请求返回 HTTP 200。若 shell 启动失败，贴出 systemd 验证/状态和相关日志；遮住密码、密钥、完整 DSN。此时仍未配置 HTTPS 公网反向代理，Google 登录和 T03 受控调用尚未验收；不运行生成请求。
