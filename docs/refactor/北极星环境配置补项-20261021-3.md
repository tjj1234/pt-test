# 北极星部署：环境配置补项

原环境文件有 23 行且格式检查通过。现在只需追加 2 个非秘密运行设置。

1. 在服务器 SSH 提示符单独执行第 13 行打开 nano。
2. 在文件末尾新开两行，添加第 19–20 行内容。不要改动其他配置值。
3. 按 `Ctrl+O`、`Enter` 保存，再按 `Ctrl+X` 退出。
4. 执行第 26 行的无值检查；预期只输出 `格式/占位符检查通过，行数：25`。

打开配置文件（第 13 行）：

```bash
sudo nano /etc/northstar/northstar.env
```

追加到文件末尾（第 19–20 行）：

```dotenv
PT_LOG_DIR=/var/lib/northstar/runtime/logs
TRUST_PROXY=1
```

无值检查（第 26 行）：

```bash
sudo awk -F= 'NF < 2 {print "格式错误：第 " NR " 行"; bad=1; next} /[<>]/ {print "仍有占位符：第 " NR " 行（" $1 "）"; bad=1} END {if (!NR) print "环境文件为空"; else if (!bad) print "格式/占位符检查通过，行数：" NR}' /etc/northstar/northstar.env
```

不要回传环境文件内容。`PT_LOG_DIR` 将应用日志写入 northstar 可写的持久化目录；`TRUST_PROXY=1` 仅在应用继续绑定 loopback、并由受信代理转发请求时使用。
