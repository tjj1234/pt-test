# 北极星 r2 单独解压

服务器只读检查显示目标发布目录为空；上传包 SHA-256 已与预期一致。现在只执行解压，再检查文件是否出现；先不安装依赖、不启动服务。

在服务器 SSH 终端**单独执行第 8 行**，等提示符回来后再执行第 9 行：

```bash
sudo tar -xzf /tmp/northstar-release-r2.tar.gz -C /opt/northstar/releases/controlled-trial-20261021-r2
sudo find /opt/northstar/releases/controlled-trial-20261021-r2 -maxdepth 2 -type d -print
```

预期第二条列出 `shell/`、`analytics/`、`business/`（以及更深一层的 `business/attribution/`）。如果解压报错，或第二条仍只列出发布根目录，停下并贴出两条命令各自的完整输出；不要重复粘贴整组命令。
