# 北极星 candidate-33 r4 目标机只读基线采集（未授权部署）

目的：确定当前线上 candidate-33 r2 的实际 Linux/Node 与 systemd 有效配置，供后续按真实 fragment、drop-in 和环境文件路径编写精确备份及回滚命令。本清单只有只读查询；不上传 r4、不修改服务、不重启、不请求 `/api/models` 或 `/api/chat`。请每步单独执行并回传该步输出；若输出意外含 Key、Cookie、Authorization、环境变量值或其他秘密，先在目标机侧遮盖该值再回传，保留属性名及非秘密路径。`ExecStart` 若含额外参数，只回传可执行文件和 server 路径，其余参数先在目标机侧脱敏。

1. 平台：

```bash
uname -s
```

2. 架构：

```bash
uname -m
```

3. 目标 Node 版本：

```bash
/usr/local/bin/node --version
```

4. 当前服务状态：

```bash
sudo systemctl is-active northstar-shell
```

5. 当前有效 unit 的非秘密属性：

```bash
sudo systemctl show northstar-shell --no-pager --property=FragmentPath --property=DropInPaths --property=ExecStart --property=WorkingDirectory --property=EnvironmentFiles --property=User --property=Group --property=LoadState --property=ActiveState
```

到此停止采集并回传以上五步输出。不要运行 `systemctl cat`、`systemctl show -p Environment`、`journalctl`，不要打印 env 文件或 unit 全文。取得第 5 步的实际 FragmentPath/DropInPaths 后，我们再逐项给出只读取路径、symlink、owner/mode 与 SHA-256 的精确命令；任何 generator/transient unit、未知 drop-in 或不明 symlink 都先停止，不猜测部署或回滚路径。
