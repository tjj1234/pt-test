# 北极星 r2 发布目录权限与锁文件核对

r2 已解压成功。tar 对 macOS provenance 扩展属性的提示不影响解压结果。接下来设置发布目录归属并核对 lockfile；此步骤不启动应用。

在服务器 SSH 终端逐条执行第 8–10 行，每条等提示符回来后再执行下一条：

```bash
sudo chown -R root:root /opt/northstar/releases/controlled-trial-20261021-r2
sudo stat -c '%U:%G %a %n' /opt/northstar/releases/controlled-trial-20261021-r2 /opt/northstar/releases/controlled-trial-20261021-r2/shell /opt/northstar/releases/controlled-trial-20261021-r2/analytics /opt/northstar/releases/controlled-trial-20261021-r2/business/attribution
sudo find /opt/northstar/releases/controlled-trial-20261021-r2 -maxdepth 4 -type f -name package-lock.json -print
```

预期：所有目录均为 `root:root`，发布根目录权限为 `755`；第三条列出 `shell/package-lock.json`、`analytics/package-lock.json`、`business/attribution/package-lock.json`。若通过，再回到 r2 替换步骤执行第 33–35 行安装依赖；逐条执行并回传各自结束输出。
