# 北极星 r4 shell 单次启动与健康检查

`psql`、直接调用 r4 `db-pg.cjs`、以及 systemd 使用正式 `EnvironmentFile=` 的回滚探测都通过；数据库迁移记录仍为空。现在启动正式 shell，让程序按文件顺序应用迁移并监听 loopback `127.0.0.1:8098`。该服务当前配置 `Restart=on-failure`；若启动失败，马上停止 unit，避免重复重试。健康检查通过只表示进程与本机 HTTP 路由可用，不代表 OAuth、反代公网 HTTPS 或 T03 验收完成。

在服务器 SSH 终端逐条执行第 8–12 行：

```bash
sudo systemctl reset-failed northstar-shell
sudo systemctl start northstar-shell
sudo systemctl is-active northstar-shell
sudo journalctl -u northstar-shell -n 60 --no-pager
curl -fsS http://127.0.0.1:8098/healthz
```

若第 10 行不是 `active`，立即执行下面的停止命令，再把第 10–11 行结果贴回；不要执行健康检查，也不要反复重启：

```bash
sudo systemctl stop northstar-shell
```

若为 `active`，第 12 行预期返回 JSON，包含 `"ok":true`。请回传第 10–12 行输出；日志若出现秘密先遮住。暂时不要开放公网端口或发起生成调用。
