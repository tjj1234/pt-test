# 北极星 shell MODULE_NOT_FOUND 诊断

shell unit 已安装，但启动日志显示 `MODULE_NOT_FOUND`。目前缺少最关键的 `Cannot find module '模块名'` 行，因此先停止失败服务并读取完整错误上下文；不重装依赖、不改 unit。

在服务器 SSH 终端逐条执行第 8–11 行：

```bash
sudo systemctl stop northstar-shell
sudo systemctl is-active northstar-shell
sudo systemctl status northstar-shell --no-pager
sudo journalctl -u northstar-shell -n 120 --no-pager -o cat
```

第二条应为 `inactive`。请把第三、四条完整输出贴回，尤其保留 `Cannot find module`、错误模块名和 require stack 的上下文；若输出意外包含密钥、密码或完整 DSN，先遮住。若第二条仍是 `active`，停下并告知状态。
