复用现有记忆CRUD、宿主Run取消、原生会话关闭及资料SHA/version墓碑；新增宿主持久来源表与范围门禁。原Gemini纯策略候选不能承担确认授权和数据库生命周期，未作为可信写入入口。所有确认来自登录宿主请求，模型没有可伪造确认的工具通路。候选推断由用户录入并标记，未宣称实现了模型自动抽取记忆。
