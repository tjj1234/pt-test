# 北极星 r4 迁移器失败后状态核查

一次性运行 r4 官方 `db.migrate()` 返回 PostgreSQL `08P01` (`pqformat.c:641`, `pq_getmsgend`)。迁移器逐文件、逐事务提交，前面的迁移可能已经成功落库；本地 r4 的 19 个 SQL 文件未发现 NUL 字节，但仍需从服务器数据库确认提交边界。shell 保持停止；不要清库、重启或手工补迁移。

在服务器 SSH 终端逐条执行第 8–10 行：

```bash
sudo -u postgres psql -d northstar -c 'SELECT name, applied_at FROM schema_migrations ORDER BY name;'
sudo -u postgres psql -d northstar -c 'SELECT count(*) AS applied_migrations FROM schema_migrations;'
sudo tail -n 100 /var/log/postgresql/postgresql-16-main.log
```

请回传三条输出。PostgreSQL 日志若出现 DSN、密码或密钥，先遮住。迁移记录中的最后一项将帮助确定失败迁移；未确认前不要再次运行迁移器。
