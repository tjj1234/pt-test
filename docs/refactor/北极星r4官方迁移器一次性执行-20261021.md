# 北极星 r4 官方迁移器一次性执行

正式 shell 当前停止。三个最小事务探测通过，而完整 `server.cjs` 启动仍失败；为推进已授权的全新受控部署，下一步改由一次性 systemd 进程调用 r4 自带的 `db.cjs` `migrate()`，不启动 HTTP 服务，也不调用 PT/模型 API。该步骤会把 19 个 schema migration 正式提交到空数据库；每个 migration 仍按应用原有事务和 `schema_migrations` 机制单独提交。若失败，回传错误和已提交记录，不启动 shell。

在服务器 SSH 终端执行第 8 行：

```bash
sudo systemd-run --wait --pipe --collect --unit=northstar-pg-migrate-r4-20261021 -p User=northstar -p Group=northstar -p WorkingDirectory=/opt/northstar/releases/controlled-trial-20261021-r4/shell -p EnvironmentFile=/etc/northstar/northstar.env -p NoNewPrivileges=yes -p PrivateTmp=yes -p ProtectSystem=strict -p ProtectHome=yes /usr/local/bin/node -e 'const dbm=require("./db.cjs");(async()=>{let x;try{x=await dbm.open({dataDir:"/var/lib/northstar/db"});const total=await dbm.migrate(x.db,"./db-migrations");const rows=await x.db.query("SELECT name FROM schema_migrations ORDER BY name");console.log("MIGRATOR_TOTAL="+total);console.log("MIGRATIONS_APPLIED="+rows.rows.length);console.log(rows.rows.map(r=>r.name).join("\n"));}catch(e){console.error("MIGRATOR_FAILED code="+(e.code||"none")+" file="+(e.file||"none")+" line="+(e.line||"none")+" routine="+(e.routine||"none")+" message="+(e.message||""));process.exitCode=1;}finally{if(x)await x.close();}})();'
```

成功时预期 `MIGRATOR_TOTAL=19`、`MIGRATIONS_APPLIED=19`，并列出 19 个迁移文件名。只回传输出；若错误包含 DSN、密码或密钥，先遮住。不要重启正式 shell 服务，等确认结果后再进行下一步。
