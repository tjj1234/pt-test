# 北极星 shell 状态命令无输出处理

`systemctl is-active northstar-shell` 正常会输出 `active`、`inactive` 等状态。若命令已返回 shell 提示符但没有任何输出，不要猜测状态，也不要把后续命令整段执行：第 12 行会停止服务，第 11 行会请求健康端点。

在服务器 SSH 终端只执行第 8 行：

```bash
sudo systemctl status northstar-shell --no-pager -l
```

如果显示 `Active: active (running)`，再执行[启动后状态确认文档第 10–11 行](北极星shell启动后状态确认-20261021.md)：查看日志并请求本机健康端点。如果显示 `failed`、`activating`、`auto-restart`、`inactive` 或其他非运行状态，执行该文档第 12 行停止服务，再回传状态与日志。若这条 `status` 命令也没有输出，先确认终端是否回到 `$` 提示符；没回到提示符就等待命令结束，不要输入下一条。
