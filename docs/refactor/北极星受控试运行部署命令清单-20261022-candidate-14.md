**2. 服务器校验字节与归档。** SSH 登录测试机后执行：

```bash
sha256sum /tmp/northstar-release-candidate-14.tar.gz /tmp/northstar-shell-candidate-14.service
gzip -dc /tmp/northstar-release-candidate-14.tar.gz | file -
tar -tzf /tmp/northstar-release-candidate-14.tar.gz > /tmp/northstar-candidate-14-files.txt
printf 'SQL_MIGRATION_FILES='; grep -Ec '^shell/db-migrations/[0-9]{3}[^/]*\.sql$' /tmp/northstar-candidate-14-files.txt
printf 'FORBIDDEN_PATHS='; (grep -Ec '(^|/)(\.env($|\.)|secrets/|node_modules/|\.git/)' /tmp/northstar-candidate-14-files.txt || true)
printf 'APPLEDOUBLE_PATHS='; (grep -Ec '(^|/)\._[^/]*(/|$)|(^|/)__MACOSX(/|$)' /tmp/northstar-candidate-14-files.txt || true)
```

成功条件：两个 SHA-256 与表格逐字一致；解压 gzip 后 `file -` 标为 POSIX tar archive；`SQL_MIGRATION_FILES=19`、`FORBIDDEN_PATHS=0`、`APPLEDOUBLE_PATHS=0`。本地已对 checksum 对应的 candidate-14 原始 tar headers 全量确认 USTAR、无 PAX/GNU 扩展头，因此远端逐字节 checksum 匹配即绑定该格式审计结果。否则停下，不解压、不停止现有服务。
