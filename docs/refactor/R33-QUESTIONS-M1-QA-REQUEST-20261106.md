| 场景 | 预期 |
|---|---|
| 默认未勾选 | 模型工具集中不开放 ask_user_question；默认预算不扩大 |
| 勾选普通澄清 | 出现明确问题及选项；未作答前原 Run 等待；回答后原 Run 继续 |
| 自定义、单选、多选 | 合法输入可提交；非法选项、空回答及单选多值被拒绝 |
| 刷新、换对话、重开 | 同一待答问题恢复，不重复创建或自动回答，不串到其他对话 |
| 超时与晚答 | 超时终态固定；晚答不恢复 Run；页面显示已过期 |
| 取消前/等待中/回答后 | 不遗留可用待答项；已成功答复记录不被改写为取消 |
| 两窗口重复回答 | 仅一次成功；另一窗口获得已终结结果 |
| 非所有者 | 不能读取或回答他人 Run；不同租户、用户、Run、call 同 ID 不互相影响 |
| 存储故障/进程重启 | 不虚构成功、取消或超时；已有终态可重读 |
| 审批、文件系统、脚本 | 不因普通澄清开放执行能力；审批请求保持关闭 |
