# 北极星 shell 启动后状态确认

`systemctl start northstar-shell` 没有输出是正常现象；它不会显示 `inactive`，需另查 unit 状态。先执行第 8 行。若输出为 `active`，再执行第 9–11 行确认日志与健康端点；若输出为 `activating`、`failed`、`inactive` 或其他非 `active`，立即执行第 12 行停止自动重启，再执行第 9–10 行取证并回传。不要重复 `start` 或 `reset-failed`。

在服务器 SSH 终端按上述条件执行：

```bash
sudo systemctl is-active northstar-shell
sudo systemctl status northstar-shell --no-pager -l
sudo journalctl -u northstar-shell -n 80 --no-pager -o short-iso
curl -fsS http://127.0.0.1:8098/healthz
sudo systemctl stop northstar-shell
```

只有第 8 行结果为 `active` 时才执行健康检查。若不是 `active`，先停止服务，再回传状态和日志。日志若含 DSN、密码或密钥，先遮住。
