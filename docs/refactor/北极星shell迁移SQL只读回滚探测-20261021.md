# 北极星 shell 首个迁移回滚探测

PostgreSQL TCP 登录成功，`schema_migrations` 存在且为空。为区分首个 SQL 本身与 node-postgres 执行路径，下面用 `psql` 在事务内执行 r4 的 `001_auth.sql`，随后回滚；成功时不会留下迁移表或身份表。若 SQL 报错，`ON_ERROR_STOP` 会断开会话，PostgreSQL 会自动回滚未提交事务。不要启动 shell 服务。

在服务器 SSH 终端逐条执行第 8–10 行：

```bash
psql -h 127.0.0.1 -U northstar_app -d northstar -W -v ON_ERROR_STOP=1 -c 'BEGIN' -f /opt/northstar/releases/controlled-trial-20261021-r4/shell/db-migrations/001_auth.sql -c 'ROLLBACK'
sudo -u postgres psql -d northstar -c '\dt'
node -p "require('/opt/northstar/releases/controlled-trial-20261021-r4/shell/node_modules/pg/package.json').version"
```

第一条会提示输入数据库密码，输入不回显；不要粘贴密码。请贴出三条结果，若 `psql` 输出错误请完整保留错误文本。不要贴环境文件内容，也不要重启服务。
